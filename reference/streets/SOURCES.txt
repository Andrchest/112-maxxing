Coverage notes (E23 recon; not decided here, Q-E11-2/Q-E23-1..4):
- 45242 ways, 5629 unique names; no okrug/district column (way tags only — a district would need
  a spatial join with admin boundaries, not attempted).
- The official street classifier (data.mos.ru, classifier 2044) needs a registered apidata.mos.ru
  api_key (HTTP 403 without one) — an owner action, not fetched (Q-E23-1).
- ФИАС's `gar_xml.zip` is ~57.7 GB with no regional subset and was not fetched (still not fetched,
  I5 E41 — outside CHANGE A's 30-minute box for a 61 MB archive).
- Both «Дубнинская улица» and «Дубининская улица» are real Moscow streets in this list — a
  directory lookup alone cannot tell which one a caller meant (Q-E23-3).

Licence: КЛАДР (Классификатор Адресов Российской Федерации) is published by ФНС России (the
Federal Tax Service) as open data at `https://fias.nalog.ru/`; no attribution string is required
the way ODbL's is, but the source and fetch date are recorded here for provenance.

Not a WorldTruth source and not scoring data (INV 3): a report-only reference list, read at report
time only (D35), on the 112 card path only. Absent both files, the report section says «Проверка
недоступна»; absent the КЛАДР file alone, the directory still loads and checks OSM only (I5 E41,
`street_directory.py`'s own module doc). Street names in the scenarios are never changed to match
this list — see D-h and `docs/hld/00-decisions.md` D35 on `scenarios/tickets/ticket-15-call-3`'s
«ул. Зверенецкая».
