# S02. Полный цикл занятия: от создания до отчёта у стажёра и журнала администратора

<!-- Файл создан из frontend/e2e/scenarios (make e2e-scenarios-doc). Правьте определения, не этот файл. -->

**Цель.** Главный путь продукта целиком (как docs/demo-scenario.md): преподаватель создаёт и запускает занятие, стажёр в роли ДДС получает карточку сам, ведёт службы по памятке и закрывает происшествие, занятие завершается само, отчёт 18/18 «Сдал» выдаётся стажёру и виден ему в «Истории», администратор видит действия в журнале.

**Вкладки (роли):** Администратор, Преподаватель, Новый стажёр.

**Перед началом:**

- Вход ещё не выполнен ни в одной вкладке (или нажмите «Выйти» во всех).

**Тестовые данные** (`<суффикс>` — придумайте в начале сценария, см. 00-instructions.md):

- Новый стажёр: логин `e2e-<суффикс>-newtrainee`, «Отображаемое имя» `Стажёр <суффикс>`, роль «Стажёр», пароль `Pw-<суффикс>-Aa1!`.
- Занятие: «Название занятия» `e2e S02 <суффикс>`.
- Номер наряда пожарной службы `Н-101`.
