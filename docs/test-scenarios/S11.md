# S11. Экспорт: настройки (XML) без паролей и ключей, профиль стажёра (JSON) без хэша пароля

<!-- Файл создан из frontend/e2e/scenarios (make e2e-scenarios-doc). Правьте определения, не этот файл. -->

**Цель.** Выгрузки не раскрывают секреты: «Экспорт настроек (XML)» у администратора — только несекретные настройки; «Скачать профиль (JSON)» у стажёра — данные и итоги без пароля и его хэша.

**Вкладки (роли):** Администратор, Стажёр (учётная запись trainee).

**Перед началом:**

- Вход ещё не выполнен ни в одной вкладке (или нажмите «Выйти» во всех). Браузер сохраняет скачанные файлы.

**Тестовые данные** (`<суффикс>` — придумайте в начале сценария, см. 00-instructions.md):

- Учётные записи `admin` и `trainee`. Ничего не создаётся.
