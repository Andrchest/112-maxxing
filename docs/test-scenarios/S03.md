# S03. Валидация ДДС: обязательный комментарий и порядок статусов службы

<!-- Файл создан из frontend/e2e/scenarios (make e2e-scenarios-doc). Правьте определения, не этот файл. -->

**Цель.** Форма статуса службы у ДДС не принимает «Не принята» и «Отказ от выполнения работ» без комментария (видно сообщение «Укажите комментарий.», статус не сохраняется) и предлагает статусы строго по порядку памятки: сначала только «Принята»/«Не принята», потом «Начало реагирования», потом «Прибытие» и т. д.

**Вкладки (роли):** Администратор, Преподаватель, Новый стажёр.

**Перед началом:**

- Вход ещё не выполнен ни в одной вкладке (или нажмите «Выйти» во всех).

**Тестовые данные** (`<суффикс>` — придумайте в начале сценария, см. 00-instructions.md):

- Новый стажёр: логин `e2e-<суффикс>-newtrainee`, «Отображаемое имя» `Стажёр <суффикс>`, роль «Стажёр», пароль `Pw-<суффикс>-Aa1!`.
- Занятие: «Название занятия» `e2e S03 <суффикс>`. Номер наряда `Н-1`.
