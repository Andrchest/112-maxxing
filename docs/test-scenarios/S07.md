# S07. Досрочное прерывание: «Прервать занятие» — карточка в отчёте без баллов

<!-- Файл создан из frontend/e2e/scenarios (make e2e-scenarios-doc). Правьте определения, не этот файл. -->

**Цель.** Преподаватель прерывает идущее занятие («Прервать занятие» с причиной): занятие и карточка «Прервано», в «Отчёты по карточкам» карточка помечена «Без оценки: карточка не завершена», баллов нет.

**Вкладки (роли):** Администратор, Преподаватель, Новый стажёр.

**Перед началом:**

- Вход ещё не выполнен ни в одной вкладке (или нажмите «Выйти» во всех).

**Тестовые данные** (`<суффикс>` — придумайте в начале сценария, см. 00-instructions.md):

- Новый стажёр: логин `e2e-<суффикс>-newtrainee`, «Отображаемое имя» `Стажёр <суффикс>`, роль «Стажёр», пароль `Pw-<суффикс>-Aa1!`.
- Занятие: «Название занятия» `e2e S07 <суффикс>`. Причина прерывания «Проверка прерывания».
