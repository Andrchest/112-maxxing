# S14. Сценарии: список у преподавателя, архив и возврат из архива меняют форму занятия

<!-- Файл создан из frontend/e2e/scenarios (make e2e-scenarios-doc). Правьте определения, не этот файл. -->

**Цель.** Преподаватель видит список сценариев в «Сценарии». Архивированный сценарий пропадает из списка (и виден с «Показывать архивные» с пометкой «В архиве») и из списка «Сценарий» формы занятия; «Вернуть из архива» возвращает его в форму.

**Вкладки (роли):** Преподаватель.

**Перед началом:**

- Вход ещё не выполнен ни в одной вкладке (или нажмите «Выйти» во всех).
- Сценарий «Горит мусор на улице, Москва, СЗАО, Щукино» не в архиве (стенд по умолчанию).

**Тестовые данные** (`<суффикс>` — придумайте в начале сценария, см. 00-instructions.md):

- Архивируется и возвращается сценарий «Горит мусор на улице, Москва, СЗАО, Щукино» (на время сценария; им не пользуются другие сценарии).

## Шаги

| Шаг | Что сделать | Должно быть видно |
|---|---|---|
| S14.01 | **Преподаватель:** Открыть новую вкладку браузера для этой роли и набрать адрес стенда + «/login» (страница входа). | • заголовок «Вход в систему»<br>• поле «Имя пользователя»<br>• поле «Пароль»<br>• кнопка «Войти», активна |
| S14.02 | **Преподаватель:** Ввести логин и пароль преподавателя (instructor), нажать «Войти». | • открылась домашняя страница роли (/instructor/lessons)<br>• заголовок «Занятия (несколько карточек)»<br>• меню «Занятия · Сессии · Статистика · Сценарии · Материалы», пункт «Занятия» подсвечен<br>• справа вверху кнопка «Выйти» |
| S14.03 | **Преподаватель:** Посмотреть в форму «Новое занятие (несколько карточек)»: открыть список «Сценарий» в блоке «Карточка 1». | • в списке «Сценарий» есть «Сложность 2 · Горит мусор на улице, Москва, СЗАО, Щукино» |
| S14.04 | **Преподаватель:** В шапке, в меню, нажать «Сценарии». | • заголовок «Сценарии»<br>• кнопка выбора файла «Файл сценария (YAML или JSON)»<br>• кнопка «Проверить» (неактивна, пока файл не выбран)<br>• кнопка «Импортировать» (неактивна, пока файл не выбран)<br>• галочка «Показывать архивные»<br>• в списке «Горит мусор на улице, Москва, СЗАО, Щукино» и «Билет 1, вызов 1: …», у каждого кнопка «Архивировать» |
| S14.05 | **Преподаватель:** У сценария «Горит мусор на улице, Москва, СЗАО, Щукино» нажать «Архивировать». | • сценарий пропал из списка |
| S14.06 | **Преподаватель:** Отметить галочку «Показывать архивные». | • «Горит мусор на улице, Москва, СЗАО, Щукино» снова в списке с пометкой «В архиве» и кнопкой «Вернуть из архива» |
| S14.07 | **Преподаватель:** В шапке нажать «Занятия» и открыть список «Сценарий» в форме «Новое занятие (несколько карточек)». | • архивного «Сложность 2 · Горит мусор на улице, Москва, СЗАО, Щукино» в списке «Сценарий» нет |
| S14.08 | **Преподаватель:** В шапке нажать «Сценарии», отметить «Показывать архивные», у «Горит мусор на улице, Москва, СЗАО, Щукино» нажать «Вернуть из архива». | • пометки «В архиве» у сценария нет, кнопка снова «Архивировать» |
| S14.09 | **Преподаватель:** В шапке нажать «Занятия» и открыть список «Сценарий» в форме занятия. | • «Сложность 2 · Горит мусор на улице, Москва, СЗАО, Щукино» снова в списке «Сценарий» |

## Уборка (выполнить всегда, даже если сценарий СЛОМАН)

- Если «Горит мусор на улице, Москва, СЗАО, Щукино» остался в архиве: «Сценарии» → «Показывать архивные» → «Вернуть из архива».
