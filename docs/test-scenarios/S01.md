# S01. Вход и выход для трёх ролей, меню своей роли, чужие разделы недоступны

<!-- Файл создан из frontend/e2e/scenarios (make e2e-scenarios-doc). Правьте определения, не этот файл. -->

**Цель.** Каждая роль входит под своим логином, видит только меню своей роли и кнопку «Выйти» на каждой странице; чужой раздел, открытый по адресу, не открывается; после «Выйти» без входа ничего не открывается.

**Вкладки (роли):** Стажёр (учётная запись trainee), Преподаватель, Администратор.

**Перед началом:**

- Стенд открыт в браузере; ни одна вкладка не выполнила вход (или нажмите «Выйти»).

**Тестовые данные** (`<суффикс>` — придумайте в начале сценария, см. 00-instructions.md):

- Учётные записи `trainee`, `instructor`, `admin` (пароли — в access.md). Ничего не создаётся.
