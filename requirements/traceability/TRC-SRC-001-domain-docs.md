# TRC-SRC-001-domain-docs — Traceability matrix: SRC-001 domain documents vs. repository

Source: `requirements/normalized/SRC-001-domain-docs.md` (REQ-3001–REQ-3049; real Moscow-112
card/DDS/classifier domain documents, not a product spec — see that file's method notes). Compared
against `docs/SPEC.md` (the build's contract) and the repository (`backend/app`, `frontend/src`,
`docs/AUDIT.md`, `docs/DOD_WALK.md`, `docs/hld/*.md`).

Global finding used throughout: `docs/SPEC.md`, `docs/AUDIT.md`, `docs/DOD_WALK.md`, `docs/hld/*.md`
and `README.md` contain zero occurrences of "классификатор"/"classifier", "Москв"/"Moscow", "ДДС",
or any of the real card's Russian field/button names (checked by grep across all five). `docs/SPEC.md`
§1 describes a generic, unnamed "local AI-powered training and assessment simulator", never the real
"Модуль «Прием и обработка вызовов 112»" system these five files document. So for almost every item
below, `SPEC.md` coverage is `not covered` (SPEC never names this real-system specific), and the
`Status` judges only whether the *product's own* generic equivalent structurally matches the real
fact.
