## Method

- **SPEC.md** column: `same` (quote of `docs/SPEC.md` §), `not covered`, or `differs` (both sides
  quoted). "nearest:" names the closest SPEC text when the SPEC touches the topic without stating
  the ТЗ item.
- **Evidence**: only files that were opened. Paths are relative to the repository root.
  `path:N` = line N; `path::test` = a test function. `AUDIT` = `docs/AUDIT.md`, `DOD` =
  `docs/DOD_WALK.md`, `RUNBOOK` = `docs/RUNBOOK.md`, `ru.ts` = `frontend/src/shared/i18n/ru.ts`,
  `v1.yaml` = `scenarios/examples/apartment-fire/v1.yaml`.
- **Status**: only `соблюдено` / `частично` / `не соблюдено` / `не обработано`
  (`requirements/README.md`). Items that state no checkable obligation (term definitions,
  motivation, expected-outcome statements, issuing parties) are `не обработано`; the reason is in
  the Gap cell and in the list at the end.
