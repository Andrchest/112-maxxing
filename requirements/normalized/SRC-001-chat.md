# SRC-001 — Telegram Q&A chat (task #9, "112" dispatcher simulator hackathon)

## 1. Coverage, method, and how organizers were identified

**Source covered:** `requirements/sources/01-qna-session-telegram/messages.html` (Telegram desktop
HTML export, 440 `message` divs: 407 real messages + 33 date-separator "service" messages spanning
29.06.2026–22.09.2026). Attachment folders next to it: `./files`, `./photos`, `./images` (chat-UI
icons, not content), `./video_files`.

**Tools used:** Parsed `messages.html` with Python 3 + BeautifulSoup (`html.parser`); `<br>` tags
converted to newlines, `<a>` targets kept, reply-to targets resolved via the `onclick="GoToMessage(N)"`
attribute (Telegram export embeds the exact parent-message id, so most Q→A pairs below are ID-verified,
not guessed from proximity). Output dumped to a full chronological transcript and cross-checked against
the raw HTML for the messages quoted here. Images referenced from organizer messages were opened and
viewed directly (screenshots described factually).

**What was in scope vs out of scope (per task brief):** every message's text (all 407) was read in
full. Photos/images attached to **organizer** messages (channel account and moderator) were viewed.
Photos attached to participant messages, the files in `./files`, and the video in `./video_files` are
other tasks' sources — this file only records, for each such attachment, which message attached it, by
whom, when, and what the message text said about it; their content is not extracted here.

**What could NOT be read:** the video Q&A-session recording itself (`./video_files/IMG_2549.MP4` is a
sticker video, not the Q&A recording — the actual recording is only a hyperlink inside message468,
`"🔗 Ссылка на запись"`, whose href is an external Yandex Telemost/cloud link not resolvable from the
static HTML export and not fetched, per read-only/no-network scope of this task). Anything organizers
said only verbally in that live stream and not repeated in chat text is therefore not represented here
as fact — see §"unreadable" in the short report.

**How organizers were identified:**
- The channel account **"Задача #9 | Департамент по делам гражданской обороны, чрезвычайным ситуациям
  и пожарной безопасности | ЛЦТ 26"** (27 messages) is the official broadcast account: it welcomes
  participants "от Департамента..." (message6), posts the chat rules distinguishing "участников,
  модераторов, экспертов и организаторов" (message7), and posts every hackathon-wide logistics
  announcement (deadlines, SourceCraft, promo codes, stop-code rules). Tagged **[ORG-CHANNEL]**.
- The account **"Str1fe"** self-identifies by name in message15: *"Меня зовут Михей, я модератор по
  задаче №9 от Департамента по делам гражданской обороны, чрезвычайным ситуациям и пожарной
  безопасности"*. Participants address it as `@str1fffff`. It repeatedly relays answers explicitly

- All other 37 named senders (Str1fe/channel excluded) behave as hackathon participants: they discuss
  their own team's hardware, argue about LLM choices, ask questions, joke, and are addressed by the
